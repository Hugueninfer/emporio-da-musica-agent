# Backend — plano de implementação

> Execução inline (prazo curto), uma tarefa por commit, testes antes do código.
> Desenho: [`docs/specs/2026-11-07-backend-design.md`](../specs/2026-11-07-backend-design.md).

**Objetivo:** agente Clave em Python que conversa com o front pronto via UI message stream.

**Arquitetura:** dados (SQLite + seções do manual) → regras puras → ferramentas puras →
agente LangGraph (Claude) → FastAPI (SSE do AI SDK). MCP expõe as mesmas ferramentas.

**Stack:** Python 3.12 · uv · LangGraph · langchain-anthropic · FastAPI · FastMCP (`mcp`) · pymupdf · pytest.

## Restrições globais

- Código e textos em português; `backend/` é um pacote uv (`src/emporio`).
- Contratos de saída = `frontend/lib/catalog.ts` (`Product`) e `frontend/lib/orders.ts` (`Order`).
- Ids de política exibidos pela UI: `1.2`, `2`, `3.1`, `4.1`, `4.2`, `5`, `7.1` (demais seções também
  podem ser citadas; a UI cai no texto original).
- "Hoje" vem de `STORE_TODAY` (ISO) ou da data local de Campo Grande (`America/Campo_Grande`).
- Contato do cliente (telefone/e-mail) nunca vai para o modelo nem para o checkpointer.
- Nenhuma tarefa até a 4 precisa da chave da Anthropic.

---

### Tarefa 1 — Dados (`emporio/data/build.py`)
- `build(data_dir, out_dir) -> {"db": Path, "policies": Path}`: CSVs → `store.db`; PDF → `policies.json`.
- Tabelas: `categories`, `products` (specs JSON), `promotions` (bool), `customers`
  (telefone só dígitos, e-mail minúsculo), `orders`, `order_items`.
- `policies.json`: lista `{id, titulo, documento, texto}` por seção numerada (1, 1.1, 1.2, 2, 3, 3.1, 4.1…).
- E-mail com acento do 1.2 é normalizado. Testes: contagens (64 produtos, 20 pedidos, 5 promoções
  ativas), seções `4.1`/`3.1` contêm "7 (sete) dias" / "R$ 80,00", e-mail normalizado.

### Tarefa 2 — Regras (`emporio/rules.py`)
- `min_installment(n)`, `installment_options(total)`, `pix_price(preco, tem_promo)`,
  `promo_price(preco, percent)`, `return_deadlines(order_date, delivered_on)`,
  `store_status(now)` (seg–sex 9–18, sáb 9–13, dom e feriados nacionais fechados).
- Testes de borda: 3x de R$ 150 ok / 4x de R$ 300 = 75 → fora; Pix com promo → `None`;
  sábado 12:59 aberta / 13:00 fechada; domingo → abre segunda 09:00.

### Tarefa 3 — Ferramentas (`emporio/tools.py` + `emporio/store.py`)
- `Store` lê o SQLite e monta `Product`/`Order`. Funções puras com os contratos do desenho.
- `consultar_pedido` compara contato por telefone (dígitos, aceita com/sem DDD) ou e-mail; nunca
  devolve o contato. Testes: busca por cordas/categoria/preço, promoções ativas (4), pagamento do
  produto 90 (promo → sem Pix), pedido 8 com telefone certo/errado, política de devolução.

### Tarefa 4 — Agente (`emporio/agent/`)
- `prompt.py`: persona Clave + regras; `graph.py`: `build_agent(model=None, checkpointer=None)`
  com `create_react_agent` e ferramentas LangChain que embrulham `emporio.tools`.
- Teste com modelo falso (`GenericFakeChatModel`/tool calls) verificando que a ferramenta roda.

### Tarefa 5 — API (`emporio/api/`)
- `stream.py`: converte eventos do LangGraph (`astream` modo `messages` + `updates`) em chunks do
  AI SDK. `app.py`: `POST /api/chat`, CORS, pré-verificação LGPD, `GET /health`.
- Teste: agente falso → sequência `start … text-delta … tool-output-available … finish`.

### Tarefa 6 — Integração com o front
- `NEXT_PUBLIC_CHAT_API` em `frontend/.env.example`; rodar os dois e conferir no navegador.

### Tarefa 7 — MCP (`emporio/mcp_server.py`)
- FastMCP com as mesmas funções (exceto `solicitar_verificacao`). Teste: lista de ferramentas.

### Tarefa 8 — Exemplos e README
- `scripts/run_examples.py` → `examples/*.md` (agente real). README final.
